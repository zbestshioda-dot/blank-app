# 🏙️ เมืองชีวิตนี้เลือกได้

เกมใช้ชีวิตออนไลน์แบบ **มัลติเพลเยอร์เรียลไทม์** เปิดเล่นบนเบราว์เซอร์ (มือถือ/คอม) ทุกคนเดินอยู่ในแมพเมืองเดียวกัน
หางานทำ ซื้อบ้าน ทำสวน แลกเปลี่ยนของ/เงิน โทรหาเพื่อน สั่งอาหารให้ไรเดอร์มาส่ง ฯลฯ

## เริ่มเล่น
ทุกคนเริ่มแบบ **ว่างงาน** (ไม่ต้องเลือกอาชีพตอนสมัคร) แล้วเดินเข้าไป **สมัครงานในอาคาร** ชื่อตัวละครใช้ได้เฉพาะภาษาอังกฤษ/ตัวเลข

## อาชีพ (สมัครที่ไหน / ต้องมีอะไร)
| อาชีพ | สมัครที่ | เงื่อนไข | ทำอะไร |
|---|---|---|---|
| 👔 พนักงานบริษัท | ฝ่ายบุคคล บริษัท | ปริญญาตรี | เข้างาน 08:00–17:00 นั่งที่โต๊ะทำงาน ได้ค่าแรงตามชั่วโมง มาสาย = หักเงิน 30% สาย/ขาดบ่อยถูกเลิกจ้าง (เงินเดือนเริ่มนับใหม่) |
| 🌾 เกษตรกร | สหกรณ์ในไร่ชานเมือง | – | ซื้อสวนของตัวเอง (เริ่ม 2 แปลง ขยายได้ถึง 6) ขายที่จุดรับซื้อในไร่หรือตลาดกลาง |
| 🎣 ชาวประมง | สมาคมประมง (ริมทะเลสาบ) | – | ตกปลา 3 แหล่ง: แม่น้ำ / ทะเลสาบ / ทะเล ได้ปลาต่างกัน |
| 🛒 พ่อค้า | คลังสินค้า | – | ซื้อราคาส่ง (สต็อกจำกัด) ไปวางขายที่ตลาดกลาง |
| 🍳 เชฟ | ครัวใหญ่ | ใบรับรองเชฟ | ปรุงอาหารจากวัตถุดิบของผู้เล่น |
| 🩺 แพทย์ | โรงพยาบาล | ปริญญาตรี + ใบประกอบวิชาชีพ | รักษาคนไข้บนเตียง (ผู้เล่น + ชาวเมือง NPC) ช่วยคนหมดสติ — ไม่มีปุ่มเข้าเวร |
| 🛵 ไรเดอร์ส่งอาหาร | ศูนย์ไรเดอร์ | ใบขับขี่ + มอเตอร์ไซค์ | รับออเดอร์จากแอพ ไปรับที่ร้านอาหาร แล้วไปส่งถึงตัวลูกค้า |

- **เปลี่ยนงานมีคูลดาวน์** ยิ่งเปลี่ยนบ่อยยิ่งนาน (10 นาที → 30 → 1 ชม. → 2 ชม. → 4 ชม. → 8 ชม.)
- **มหาวิทยาลัย**: ลงทะเบียน ฿3,500 แล้วเข้าเรียน 6 คาบ (คาบละ 1 ชม.ในเกม) ได้ปริญญาตรี · ใบรับรองเชฟ / ใบประกอบวิชาชีพแพทย์ซื้อได้ที่นี่ · **ใบขับขี่** สอบที่โชว์รูมรถ
- 🏅 **ความสำเร็จ → ฉายาบนหัว** แต่ละอาชีพมีฉายาให้ปลดล็อก เลือกฉายาที่จะแสดงได้

## โลก
- 🗺️ 3 แผนที่ + ภายในอาคาร: **ตัวเมือง** (110×90 ถนนคดเคี้ยว จัตุรัสกลางเมืองมีโต๊ะนั่งเล่น ทะเลสาบ ชายหาด ที่ดินว่างสำหรับอาชีพใหม่), **ไร่ชานเมือง** (สวนของผู้เล่น 10 แปลง + แม่น้ำ), **หมู่บ้านจัดสรร** (บ้าน 12 หลัง ซื้อ/ขาย/เช่า/ปล่อยเช่าได้) เดินทางผ่านประตูเมือง
- 🕐 1 วันในเกม = 24 นาที ทุกสถานที่มี **เวลาเปิด-ปิด** (บริษัท 06:00–21:00 หลัง 17:00 ไฟในออฟฟิศดับ, โรงพยาบาลเปิด 24 ชม.) ถึงเวลาปิดคนในอาคารจะถูกพาออกไปข้างนอก
- 🚪 เข้า/ออกอาคารด้วยการ **กดปุ่ม** (มีคูลดาวน์ ไม่เด้งเข้าออก) อยู่ในอาคารจะไม่เห็นข้างนอก เฟอร์นิเจอร์ชนได้จริง

## สุขภาพ
- หิวนานเลือดลด · ป่วยบ่อยขึ้น (ตากฝน, ติดจากคนใกล้ๆ, ไข้หวัดใหญ่ระบาดทำเลือดลดเร็วมาก)
- **เลือดหมด** → หมดสติ ถูกส่งไปนอนเตียงโรงพยาบาล ทำอะไรไม่ได้จนหมอช่วย (ไม่มีหมอ: เจ้าหน้าที่ช่วยแต่แพง)
- **หิวจนเลือดหมด** → ล้มนอนเป็นผักตรงนั้น เลือดค่อยๆ ฟื้นแล้วลุกได้เอง
- ไม่มีบ้านก็ **นั่งพักหลับตา** ได้ทุกที่ (ปุ่ม 😌 / R) พลังงานฟื้นเร็ว 3 เท่า

## เศรษฐกิจ (กันเงินเฟ้อ)
- NPC รับซื้อแค่ ~35% ของราคาตลาด (จุดรับซื้อในไร่/สมาคมประมง ~45%) ขายให้ผู้เล่นที่ตลาดกลางได้ราคาดีกว่ามาก
- ตลาดกลางมี **ค้นหาชื่อสินค้า** และ **แยกหมวด** (พืชผล / ปลา / อาหาร / สินค้า)
- รายได้ เควสต์ โบนัสรายวัน ดอกเบี้ยธนาคาร ถูกลดลง ของใช้จ่าย (บ้าน รถ สวน ค่าเทอม ใบอนุญาต ค่าเช่า) ช่วยดึงเงินออกจากระบบ

## สังคม
- 💬 คุยในแชท = **บับเบิ้ลบนหัว** เห็นเฉพาะคนที่อยู่ใกล้ (~14 ช่อง)
- 📱 **มือถือ**: ทุกคนมีเบอร์ 6 หลัก บันทึกเบอร์เพื่อน โทรคุยกันได้ทุกที่ · แอพ **สั่งอาหาร** (ไรเดอร์ผู้เล่นมาส่งถึงตัว) · แอพไรเดอร์
- 🤝 แตะผู้เล่นอื่นเพื่อแลกเปลี่ยนของ/เงิน · หมอเสนอปฐมพยาบาลได้

## วิธีเล่น
- **เดิน**: มือถือแตะค้างแล้วลาก (จอยลอย) · คอม WASD / ลูกศร
- **ใช้สถานที่/เข้าอาคาร**: เดินไปที่ไอคอนหรือหน้าประตู แล้วกดปุ่มกลมสีเหลือง (คอม: E) · R = นั่งพัก · P = มือถือ
- เล่นต่อได้ด้วยชื่อ + PIN (เซฟลง Postgres ถ้ามี `DATABASE_URL` ไม่งั้นเซฟที่ `data/players.json`)
- ทดสอบเวลาในเกม: ตั้ง `TIME_OFFSET_MS` เพื่อเลื่อนนาฬิกา หรือเปิด `?phase=0.9` เพื่อดูแสงกลางคืน


## Deploy ให้เพื่อนเล่นออนไลน์ (ฟรี)
เกมนี้ใช้ WebSocket ต้องรันบนเซิร์ฟเวอร์ Node.js (ใช้ Streamlit Cloud ไม่ได้) ตัวอย่างบน [Render](https://render.com):
1. New → **Web Service** → เลือก repo นี้และ branch ที่ต้องการ
2. Render อ่าน `render.yaml` ให้เอง (Build: `npm install`, Start: `npm start`)
3. ได้ลิงก์ `https://xxx.onrender.com` ส่งให้เพื่อนได้เลย

### เก็บข้อมูลผู้เล่นถาวร (แนะนำ)
ถ้าไม่ตั้งค่าอะไร ข้อมูลจะเก็บในไฟล์ ซึ่งหายทุกครั้งที่ Render deploy/รีสตาร์ท ให้ใช้ Postgres ฟรีแทน:
1. สร้างฐานข้อมูลฟรีที่ [Neon](https://neon.tech) (หรือ Supabase) แล้วคัดลอก **connection string** (ขึ้นต้นด้วย `postgresql://`)
2. ใน Render → service → **Environment** → Add `DATABASE_URL` = connection string นั้น → Save
3. เซิร์ฟเวอร์สร้างตารางให้เอง เซฟทุก 15 วินาทีและตอนปิด เห็นข้อความ `storage: Postgres` ใน Logs

### กันเซิร์ฟเวอร์หลับ
บน Render เซิร์ฟเวอร์จะ ping ตัวเองทุก 9 นาที (ใช้ `RENDER_EXTERNAL_URL` ที่ Render ใส่ให้เอง หรือกำหนด `KEEPALIVE_URL` เอง) จึงไม่หลับตอนไม่มีคนเล่น

## กราฟิก
ภาพทั้งหมดมาจาก sprite sheet แนวพิกเซลอาร์ต 5 แผ่นที่ให้มา ตัดพื้นหลังสีชมพูออกและรวมเป็น `public/assets/atlas.webp` (+ `atlas.json`, 1 ช่อง = 48 px)
สร้างใหม่ได้ด้วย:
```
SHEETS_DIR=path/to/sheets/ python3 tools/slice_sheets.py      # ลบพื้นหลัง -> cut_*.png
python3 tools/segment_sprites.py                               # หา sprite -> boxes.json
python3 tools/build_atlas.py .                                 # ตัด/ประกอบตึก/รวม -> public/assets/
```
ผังเมืองสร้างจากขนาด sprite จริง (`server/data.js` อ่าน atlas.json) ตึกหันหน้าลงถนน เดินไปหลังตึก/ต้นไม้แล้วจะถูกบัง

## โครงสร้าง
- `server/data.js` แผนที่ทั้ง 3 + ภายในอาคาร (เฟอร์นิเจอร์ชนได้), เวลาเปิดปิด, ไอเทม, อาชีพ, โรค, ความสำเร็จ
- `server/quests.js` เควสต์ประจำวัน
- `server/store.js` ที่เก็บข้อมูลผู้เล่น (Postgres / ไฟล์)
- `server/index.js` เซิร์ฟเวอร์ (HTTP + WebSocket, ตรรกะเกมทั้งหมดอยู่ฝั่งเซิร์ฟเวอร์ ตรวจความเร็วเดิน/ระยะ/ของที่มีจริง)
- `public/game.js` ไคลเอนต์ (canvas) · `public/fx.js` เสียงและเอฟเฟกต์
