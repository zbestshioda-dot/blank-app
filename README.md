# 🏙️ เมืองชีวิตนี้เลือกได้

เกมใช้ชีวิตออนไลน์แบบ **มัลติเพลเยอร์เรียลไทม์** เปิดเล่นบนเบราว์เซอร์ (มือถือ/คอม) ทุกคนเดินอยู่ในแมพเมืองเดียวกัน
หางานทำ ซื้อบ้าน ทำสวน แลกเปลี่ยนของ/เงิน โทรหาเพื่อน สั่งอาหารให้ไรเดอร์มาส่ง ฯลฯ

## เริ่มเล่น
ล็อกอินด้วย **ID** (ภาษาอังกฤษ/ตัวเลข) + **PIN** · บัญชีใหม่จะได้ตั้ง **ชื่อตัวละคร** (ไทยได้ ห้ามซ้ำกับคนอื่น) และเลือกเพศ/เสื้อครั้งเดียว · ทุกคนเริ่มแบบ **ว่างงาน** (ไม่ต้องเลือกอาชีพตอนสมัคร) แล้วเดินเข้าไป **สมัครงานในอาคาร** ชื่อตัวละครใช้ได้เฉพาะภาษาอังกฤษ/ตัวเลข

## อาชีพ (สมัครที่ไหน / ต้องมีอะไร)
| อาชีพ | สมัครที่ | เงื่อนไข | ทำอะไร |
|---|---|---|---|
| 👔 พนักงานบริษัท | ฝ่ายบุคคล บริษัท | ปริญญาตรี | เข้างาน 08:00–17:00 นั่งที่โต๊ะทำงาน ได้ค่าแรงตามชั่วโมง มาสาย = หักเงิน 30% สาย/ขาดบ่อยถูกเลิกจ้าง (เงินเดือนเริ่มนับใหม่) |
| 🌾 เกษตรกร | สหกรณ์ในไร่ชานเมือง | – | ซื้อสวนของตัวเอง (เริ่ม 2 แปลง ขยายได้ถึง 6) ขายที่จุดรับซื้อในไร่หรือตลาดกลาง |
| 🛒 พ่อค้า | คลังสินค้า | – | ซื้อราคาส่ง (สต็อกจำกัด) ไปวางขายที่ตลาดกลาง |
| 🍳 เชฟ | ครัวใหญ่ | ใบรับรองเชฟ | ปรุงอาหารจากวัตถุดิบของผู้เล่น |
| 🩺 แพทย์ | โรงพยาบาล | ปริญญาตรี + ใบประกอบวิชาชีพ | **อยู่ในโรงพยาบาลช่วงเวร 08:00–20:00 ได้เงินเดือนทุกชั่วโมง** + ค่ารักษาคนไข้บนเตียง (ผู้เล่น + ชาวเมือง NPC) |
| 🛵 ไรเดอร์ส่งอาหาร | ศูนย์ไรเดอร์ | ใบขับขี่ (ต่ออายุทุกปี) | รับออเดอร์จากแอพ ไปรับที่ร้านอาหาร แล้วไปส่งถึงตัวลูกค้า |

- **สมัครงาน/เปลี่ยนงาน**: คุยกับ **NPC เจ้าหน้าที่** 💬 ที่ยืนข้างเคาน์เตอร์ของแต่ละที่ (เป็นจุดแยกจากเคาน์เตอร์ และมีหมุด 👤 แยกบนแผนที่) · เปลี่ยนงานแล้วรอ **5 นาที**
- 🎣 **ตกปลา (ทุกคน ไม่ต้องสมัคร)**: ซื้อเบ็ด ฿150 กับน้าเล็กที่สมาคมประมง — แนะนำเป็นวิธีหาเงินก้อนแรก · พอปลากินเบ็ด ขีดขาวจะวิ่งไปมา **กดตอนอยู่ในแถบเขียว** (เบ็ดอัปเกรด/เลเวลสูง แถบกว้างขึ้น) · มีเลเวลตกปลาของตัวเอง ถึง Lv.10 ได้รางวัล **ชุดนักตกปลา**
- 🕶️ **ล้วงกระเป๋า (ทุกคน ยกเว้นตำรวจ)**: ล้วงผู้เล่น/ชาวเมือง/ฝูงชน แล้ว **ใส่ชุดโจรทันที 3 นาที** · คนที่เห็นกด 📞 191 ได้ (หรือกดแจ้งจากโปรไฟล์คนที่ใส่ชุดโจร) · **สายตรวจ NPC วิ่งไล่จับ** (หนีเข้าตึก/ออกนอกเมืองได้)
- **มหาวิทยาลัย**: ลงทะเบียนแล้ว **นั่งที่โต๊ะเรียน** เหมือนพนักงานนั่งทำงาน (นั่งครบ 1 ชม.ในเกม = 1 คาบ) · ใบรับรองเชฟ / ใบประกอบวิชาชีพแพทย์ซื้อได้ที่นี่ · **สอบใบขับขี่และต่ออายุ (ทุก 1 ปีในเกม = 1 วันจริง, ฿600)** ที่นี่ · โชว์รูมรถปิดปรับปรุง (ยานพาหนะถูกนำออก คืนเงินให้ทุกคนแล้ว)
- 🏅 **ความสำเร็จ → ฉายาบนหัว** แต่ละอาชีพมีฉายาให้ปลดล็อก เลือกฉายาที่จะแสดงได้

## โลก
- 🗺️ 3 แผนที่ + ภายในอาคาร: **ตัวเมือง** (110×90 ถนนคดเคี้ยว จัตุรัสกลางเมืองมีโต๊ะนั่งเล่น ทะเลสาบ ชายหาด ที่ดินว่างสำหรับอาชีพใหม่), **ไร่ชานเมือง** (สวนของผู้เล่น 10 แปลง + แม่น้ำ), **หมู่บ้านจัดสรร** (บ้าน 12 หลัง ซื้อ/ขาย/เช่า/ปล่อยเช่าได้) เดินทางผ่านประตูเมือง
- 🕐 1 วันในเกม = 24 นาที โดย **กลางคืนผ่านไปเร็วกว่า** (05:00–20:00 ใช้ 19.5 นาที, 20:00–05:00 ใช้ 4.5 นาที) ทุกสถานที่มี **เวลาเปิด-ปิด** (บริษัท 06:00–21:00 หลัง 17:00 ไฟในออฟฟิศดับ, โรงพยาบาลและ**ตลาดกลางเปิด 24 ชม.**) ถึงเวลาปิดคนในอาคารจะถูกพาออกไปข้างนอก
- 👷 **NPC ทำงานแทน**: ถ้าไม่มีผู้เล่นอาชีพไหนออนไลน์ จะมี NPC อาชีพนั้นออกมาทำงาน (พนักงานนั่งโต๊ะ ชาวไร่ แม่ค้า เชฟ ไรเดอร์ ขอทาน) · **หมอเวร NPC** เดินดูแลคนไข้ (รักษาให้เมื่อไม่มีหมอผู้เล่น) · **สายตรวจ NPC** ลาดตระเวนตลอด
- 🚪 เข้า/ออกอาคารด้วยการ **กดปุ่ม** (มีคูลดาวน์ ไม่เด้งเข้าออก) อยู่ในอาคารจะไม่เห็นข้างนอก เฟอร์นิเจอร์ชนได้จริง

## สุขภาพ
- หิวนานเลือดลด · ป่วยบ่อยขึ้น (ตากฝน, ติดจากคนใกล้ๆ, ไข้หวัดใหญ่ระบาดทำเลือดลดเร็วมาก)
- **เลือดหมด** → หมดสติ วาร์ปไปนอนเตียงโรงพยาบาล ทำอะไรไม่ได้จนหมอช่วย มีนับถอยหลังบอกเวลาฟื้น (ไม่มีหมอ 1 นาที / มีหมอรอ 2 นาที แล้วเจ้าหน้าที่ช่วยแต่แพง)
- **หิวจนเลือดหมด** → ล้มนอนเป็นผักตรงนั้น เลือดค่อยๆ ฟื้นแล้วลุกได้เอง
- ไม่มีบ้านก็ **นั่งพักหลับตา** ได้ทุกที่ (ปุ่ม 😌 / R) พลังงานฟื้นเร็ว 3 เท่า และ**เลือดค่อยๆ ฟื้น** (ถ้าไม่หิว)
- 🍱 ซื้ออาหาร **ตุนใส่กระเป๋า** ได้ที่ร้านอาหาร · แตะแถบสถานะ (⚡🍗❤️😊) เพื่อดูวิธีเพิ่มแต่ละค่า

## ความสุข ปฏิทิน และค่าน้ำค่าไฟ
- 😊 **ความสุข** ลดลงเรื่อยๆ (หิว ป่วย ถูกล้วงกระเป๋า ถูกตัดน้ำไฟ ทำให้ลดเร็วขึ้น) ถ้าต่ำกว่า 20 จะ **ซึมเศร้า ทำงานไม่ได้** · เพิ่มได้จากกินของที่อยากกิน นั่งเล่นที่จัตุรัส โทรคุยกับเพื่อน บริจาคให้ขอทาน นอนในบ้านตัวเอง
- 🤤 **อยากกิน**: เกมจะบอกเป็นระยะว่าตัวละครอยากกินอะไร กินภายใน 6 นาทีความสุข +22
- 📅 **ปฏิทิน 12 เดือน** 1 เดือน = 5 วันในเกม (2 ชม.จริง) · คนที่มีบ้าน/เช่าบ้านได้ **บิลค่าน้ำค่าไฟทุกเดือน** (ตามจำนวนครั้งที่นอนและเฟอร์นิเจอร์) จ่ายที่ธนาคารหรือแอพในมือถือ ค้างเกินเดือนถัดไป = ค่าปรับ 15% + **ถูกตัดน้ำตัดไฟ** นอนบ้านไม่ได้
- 🔒 บ้านที่มีเจ้าของ/ผู้เช่า เข้าได้เฉพาะเจ้าของและผู้เช่า

## โจร ตำรวจ ขอทาน
- 🥣 **ขอทาน** (สมัครที่ศาลาประชาคมในจัตุรัส) **นั่งได้ทุกที่** (ปุ่ม 🥣) ที่คนพลุกพล่านได้เงินบ่อยกว่า ผู้เล่นกด 💬 คุยแล้วบริจาคได้ ผู้บริจาคมีความสุขเพิ่ม
- 🕶️ **ล้วงกระเป๋า** เป็นอาชีพเสริมของทุกคน (ไม่ใช่งานแล้ว) · คนที่เห็นจะได้ปุ่ม **📞 แจ้งตำรวจ 191** ตำแหน่งโจรขึ้น **บนแผนที่ของตำรวจเท่านั้น** · ตำรวจที่อยู่แถวนั้นตอนเกิดเหตุจับได้ทันที และสายตรวจ NPC วิ่งไล่
- 👮 **ตำรวจ** ต้องจบ **ม.6** (เรียน 4 คาบที่มหาวิทยาลัย) และ **สอบนายสิบตำรวจ** ที่มหาวิทยาลัย แล้วสมัครที่สถานีตำรวจ · ได้เบี้ยเลี้ยงตอนลาดตระเวน + ค่าหัว · จับโจร = โจรถูกปรับ (คืนเงินผู้เสียหาย) และติดคุก 2.5 นาที
- ปริญญาตรีต้องจบ ม.6 ก่อน

## รายได้โดยประมาณของแต่ละอาชีพ (Lv.1 ขายให้ NPC ต่อชั่วโมงจริง)
| อาชีพ | ประมาณ | หมายเหตุ |
|---|---|---|
| 🎣 ตกปลา (ทุกคน) | แม่น้ำ ~฿1,200 · ทะเลสาบ ~฿1,800 · ทะเล ~฿2,400 | ลงทุนแค่เบ็ด ฿150 |
| 🥣 ขอทาน | ~฿600 | ไม่ต้องลงทุน + ได้บริจาคจากผู้เล่น |
| 👮 ตำรวจ | ~฿1,100 + ค่าหัว | ต้องจบ ม.6 + สอบ |
| 👔 พนักงานบริษัท | ~฿1,200 | มั่นคง เลื่อนขั้นแล้วได้ถึง ~฿3,400 |
| 🌾 เกษตรกร | ~฿700 (2 แปลง) → ~฿2,000 (6 แปลง) | ต้องลงทุนซื้อ/ขยายสวน · ขายผู้เล่นได้มากกว่า |
| 🛒 พ่อค้า | ~฿1,300 | ร้านค้ารับซื้อสินค้าจากพ่อค้า 70% (สต็อกแชร์กัน) |
| 🍳 เชฟ | ~฿1,300 | ร้านอาหารรับซื้อจานของเชฟ 50% · วัตถุดิบจากผู้เล่นถูกกว่า |
| 🛵 ไรเดอร์ | ~฿1,800 | ต้องมีใบขับขี่ (ต่ออายุทุกปี ฿600) |
| 🩺 แพทย์ | ~฿2,000 + เงินเดือนเวร | ต้องจบปริญญาตรี + ใบประกอบวิชาชีพ |

ค่าใช้จ่ายประจำ: อาหาร ~฿500/ชม. · ค่าน้ำไฟ ~฿200–400/ชม. (ถ้ามีบ้าน)

## เศรษฐกิจ (กันเงินเฟ้อ)
- NPC รับซื้อแค่ ~30% ของราคาตลาด (จุดรับซื้อในไร่/สมาคมประมง ~38%) ตลาดหักค่าธรรมเนียม 8% · เริ่มเกมด้วยเงิน ฿600 · ค่าแรง/ค่าส่ง/โบนัส ลดลง ของแพงขึ้น ขายให้ผู้เล่นที่ตลาดกลางได้ราคาดีกว่ามาก
- ตลาดกลางมี **ค้นหาชื่อสินค้า** และ **แยกหมวด** (พืชผล / ปลา / อาหาร / สินค้า)
- รายได้ เควสต์ โบนัสรายวัน ดอกเบี้ยธนาคาร ถูกลดลง ของใช้จ่าย (บ้าน รถ สวน ค่าเทอม ใบอนุญาต ค่าเช่า) ช่วยดึงเงินออกจากระบบ

## สังคม
- 💬 คุยในแชท = **บับเบิ้ลบนหัว** เห็นเฉพาะคนที่อยู่ใกล้ (~14 ช่อง)
- 📱 **มือถือ**: ทุกคนมีเบอร์ 6 หลัก บันทึกเบอร์เพื่อน โทรคุยกันได้ทุกที่ · แอพ **สั่งอาหาร** (ไรเดอร์ผู้เล่นมาส่งถึงตัว) · แอพไรเดอร์
- 💬 **ปุ่มคุย** (นิ้วโป้งขวา / F) เปิดโปรไฟล์คนที่อยู่ใกล้สุด: แลกเปลี่ยนของ/เงิน · **📱 ขอเบอร์** (ตกลง = แลกเบอร์กัน, ปฏิเสธ 2 ครั้งต้องรอ 10 นาที) · หมอเสนอปฐมพยาบาลได้
- 😀 อิโมจิลอยบนหัว · 👥 ดูเพื่อนที่ออนไลน์ · ไม่แตะจอ 2 นาทีขึ้น **💤 ไม่อยู่** · 🗺️ แผนที่มีจุดสีผู้เล่นออนไลน์พร้อมชื่อ
- ⚙️ **ตั้งค่า**: เสียง เต็มจอ **ซ่อนชุดอาชีพ** ใส่ชุดรางวัล ชวนเพื่อน (📤 แชร์ลิงก์ — มีที่หน้าล็อกอินด้วย) **รีเซ็ตตัวละคร** (ใส่ PIN + พิมพ์ "รีเซ็ต") · 🐞 **แจ้งบัค** (แอดมินอ่านได้ใน God mode)
- 👑 **แอดมิน** (อนุทิน · «นายกเทศมนตรี» ชื่อสีรุ้งพรีเมียม) เล่นด้วยค่าปกติ มีเมนู **God mode**: ไม่มีคูลดาวน์ / ล็อกสเตตัสเต็ม / เติมสเตตัส / เงิน ฿999,999 · ห้ามผู้เล่นอื่นตั้งชื่อเลียนแบบแอดมิน/ทีมงาน
- 📢 แถบตัวหนังสือเลื่อนแจ้งว่าเซิฟเป็น CBT (ข้อมูลจะถูกรีเซ็ตเมื่อเกมสมบูรณ์) · deploy เวอร์ชันใหม่แล้ว เกมที่เปิดค้างไว้จะขึ้นปุ่ม 🔄 ให้รีเฟรช

## วิธีเล่น
- **เดิน**: มือถือแตะค้างแล้วลาก (จอยลอย) · คอม WASD / ลูกศร
- **ใช้สถานที่/เข้าอาคาร**: เดินไปที่ไอคอนหรือหน้าประตู แล้วกด **ปุ่มใหญ่สีเหลือง** ที่นิ้วโป้งขวา (คอม: E) · 💬 คุย (F) · R = นั่งพัก · P = มือถือ · เมนูอยู่แถบบนสุด · ยกเลิกนำทางได้ที่ปุ่มใต้สถานะ
- เล่นต่อได้ด้วยชื่อ + PIN (เซฟลง Postgres ถ้ามี `DATABASE_URL` ไม่งั้นเซฟที่ `data/players.json`)
- ทดสอบเวลาในเกม: ตั้ง `TIME_OFFSET_MS` เพื่อเลื่อนนาฬิกา หรือเปิด `?phase=0.9` เพื่อดูแสงกลางคืน

## Deploy ให้เพื่อนเล่นออนไลน์ (ฟรี)
เกมนี้ใช้ WebSocket ต้องรันบนเซิร์ฟเวอร์ Node.js (ใช้ Streamlit Cloud ไม่ได้) ตัวอย่างบน [Render](https://render.com):
1. New → **Web Service** → เลือก repo นี้และ branch ที่ต้องการ
2. Render อ่าน `render.yaml` ให้เอง (Build: `npm install`, Start: `npm start`)
3. ได้ลิงก์ `https://xxx.onrender.com` ส่งให้เพื่อนได้เลย

### เก็บข้อมูลผู้เล่นถาวร (แนะนำ)
ถ้าไม่ตั้งค่าอะไร ข้อมูลจะเก็บในไฟล์ ซึ่งหายทุกครั้งที่ Render deploy/รีสตาร์ท ให้ใช้ Postgres ฟรีแทน:
1. สร้างฐานข้อมูลฟรีที่ [Neon](https://neon.tech) (หรือ Supabase) แล้วคัดลอก **connection string** (ขึ้นต้นด้วย `postgresql://`)
2. ใน Render → service → **Environment** → Add `DATABASE_URL` = connection string นั้น → Save
3. เซิร์ฟเวอร์สร้างตารางให้เอง เซฟทุก 15 วินาทีและตอนปิด เห็นข้อความ `storage: Postgres` ใน Logs

### กันเซิร์ฟเวอร์หลับ
บน Render เซิร์ฟเวอร์จะ ping ตัวเองทุก 9 นาที (ใช้ `RENDER_EXTERNAL_URL` ที่ Render ใส่ให้เอง หรือกำหนด `KEEPALIVE_URL` เอง) จึงไม่หลับตอนไม่มีคนเล่น

## กราฟิก
ภาพทั้งหมดมาจาก sprite sheet แนวพิกเซลอาร์ต 5 แผ่นที่ให้มา ตัดพื้นหลังสีชมพูออกและรวมเป็น `public/assets/atlas.webp` (+ `atlas.json`, 1 ช่อง = 48 px)
สร้างใหม่ได้ด้วย:
```
SHEETS_DIR=path/to/sheets/ python3 tools/slice_sheets.py      # ลบพื้นหลัง -> cut_*.png
python3 tools/segment_sprites.py                               # หา sprite -> boxes.json
python3 tools/build_atlas.py .                                 # ตัด/ประกอบตึก/รวม -> public/assets/
```
ผังเมืองสร้างจากขนาด sprite จริง (`server/data.js` อ่าน atlas.json) ตึกหันหน้าลงถนน เดินไปหลังตึก/ต้นไม้แล้วจะถูกบัง

## โครงสร้าง
- `server/data.js` แผนที่ทั้ง 3 + ภายในอาคาร (เฟอร์นิเจอร์ชนได้), เวลาเปิดปิด, ไอเทม, อาชีพ, โรค, ความสำเร็จ
- `server/quests.js` เควสต์ประจำวัน
- `server/store.js` ที่เก็บข้อมูลผู้เล่น (Postgres / ไฟล์)
- `server/index.js` เซิร์ฟเวอร์ (HTTP + WebSocket, ตรรกะเกมทั้งหมดอยู่ฝั่งเซิร์ฟเวอร์ ตรวจความเร็วเดิน/ระยะ/ของที่มีจริง)
- `public/game.js` ไคลเอนต์ (canvas) · `public/fx.js` เสียงและเอฟเฟกต์
