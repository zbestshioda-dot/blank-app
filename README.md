# 🏙️ ชีวิตนี้เลือกได้ — เกมใช้ชีวิตออนไลน์แบบ Multiplayer

เกมจำลองชีวิตบนเบราว์เซอร์ เลือกอาชีพ หาเงินด้วยวิธีที่ต่างกัน และแข่งความรวยกับผู้เล่นคนอื่นในเมืองเดียวกันแบบเรียลไทม์

## อาชีพ (แต่ละอาชีพหาเงินไม่เหมือนกัน)
| อาชีพ | วิธีหาเงิน |
|---|---|
| 👔 พนักงานออฟฟิศ | ทำงาน/โอที รายได้มั่นคง เลื่อนตำแหน่งได้ถึง CEO |
| 🛒 พ่อค้าแม่ค้า | ซื้อราคาส่ง ขายในตลาดกลางที่ราคาแชร์กันทุกคน (เทขายเยอะ ราคาตก) |
| 🌾 เกษตรกร | ปลูกพืช รอโต (นับเวลาจริง) เก็บเกี่ยวแล้วขาย ขึ้นกับสภาพอากาศ |
| 🎣 ชาวประมง | เสี่ยงดวงตกปลา ตั้งแต่ขยะยันหีบสมบัติ |
| 🎥 สตรีมเมอร์ | สร้างผู้ติดตาม มีลุ้นไวรัล รายได้แฝงรายวัน รับโดเนทจากผู้เล่น |
| 💻 โปรแกรมเมอร์ | อ่านโค้ดแล้วตอบผลลัพธ์ ถูกได้เงิน ผิดอด (ต้องวุฒิ ม.6) |
| 🩺 แพทย์ | เข้าเวรรายได้สูง และรักษาผู้เล่นอื่นเพื่อรับค่ารักษา (ต้องวุฒิ ป.โท) |

ทุกคนลงทุนหุ้น เรียนต่อ ซื้อทรัพย์สิน (บ้าน รถ เรือ รถไถ ฯลฯ) ได้ และต้องดูแล ⚡พลังงาน ❤️สุขภาพ 😊ความสุข
1 วันในเกม = 2 นาทีจริง ทุกวันมีเหตุการณ์สุ่มที่กระทบทั้งเมือง และต้องจ่ายค่ากินอยู่/ค่าเช่า

## ระบบผู้เล่นหลายคน
ทุกคนที่เปิดเซิร์ฟเวอร์เดียวกันอยู่ในโลกเดียวกัน: แชท, ข่าวเมือง, อันดับเศรษฐี, ราคาตลาดและหุ้น,
โอนเงิน, ส่งของขวัญ, โดเนท, หมอรักษาผู้เล่น — หน้าจออัปเดตเองทุก 2–5 วินาที
เข้าเล่นต่อได้ด้วยชื่อ + PIN 4 หลัก ข้อมูลเซฟไว้ที่ `data/world.json`

## เล่นออนไลน์ให้เพื่อนเข้าได้ทันที
Deploy repo นี้บน [Streamlit Community Cloud](https://share.streamlit.io) (ฟรี) โดยชี้ไปที่ `streamlit_app.py`
แล้วส่งลิงก์ให้เพื่อน

## รันบนเครื่อง
```
pip install -r requirements.txt
streamlit run streamlit_app.py
```
เพื่อนในวง LAN เดียวกันเข้าได้ที่ `http://<IP เครื่องคุณ>:8501`
