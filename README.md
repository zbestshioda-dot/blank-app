# 🏙️ เมืองชีวิตนี้เลือกได้

เกมใช้ชีวิตออนไลน์แบบ **มัลติเพลเยอร์เรียลไทม์** เปิดเล่นบนเบราว์เซอร์ (มือถือ/คอม) ทุกคนเดินอยู่ในแมพเมืองเดียวกัน
เดินเข้าไปหากัน แลกเปลี่ยนของ/เงิน ให้หมอรักษา โดเนทสตรีมเมอร์ ฯลฯ

## อาชีพ (หาเงินไม่เหมือนกัน และเชื่อมโยงกัน)
| อาชีพ | ทำอะไร |
|---|---|
| 👔 พนักงานออฟฟิศ | ทำงาน/โอทีที่บริษัท เลื่อนขั้นได้ถึง CEO |
| 🌾 เกษตรกร | ปลูกพืชบนแปลงกลางเมือง (ใช้ร่วมกัน — ถ้าเจ้าของไม่มาเก็บ คนอื่นเก็บตัดหน้าได้!) |
| 🎣 ชาวประมง | ตกปลาที่ท่าเรือ ต้องจับจังหวะกดดึงให้ทัน ลุ้นฉลามและหีบสมบัติ |
| 🛒 พ่อค้า | ซื้อสินค้าราคาส่งจากคลัง (สต็อกจำกัด ทุกคนแย่งกัน) ไปขายให้ผู้เล่นหรือตลาดกลาง |
| 🎥 สตรีมเมอร์ | ไลฟ์สะสมแฟน รายได้แฝง ลุ้นไวรัล รับโดเนทจากผู้เล่น |
| 💻 โปรแกรมเมอร์ | อ่านโค้ดแล้วตอบผลลัพธ์ (ต้องซื้อใบรับรองที่โรงเรียน) |
| 🍳 เชฟ | รับวัตถุดิบจากชาวไร่/ชาวประมง ปรุงอาหารขายแพงกว่า (ต้องมีใบรับรอง) |
| 🩺 แพทย์ | เข้าเวร หรือเดินไปรักษาผู้เล่นอื่นรับค่ารักษา (ต้องมีใบประกอบวิชาชีพ) |

💰 **ที่ใช้เงิน**: 🚗 โชว์รูมรถ (สเก็ต→รถยนต์ เดินเร็วขึ้นสูงสุด 2 เท่า) · 🛠️ ร้านอุปกรณ์ (อัปเกรดอาชีพ 3 ระดับ) · 🏠 บ้าน 6 หลังในหมู่บ้าน + เฟอร์นิเจอร์ (นอนฟรี, พลังงานฟื้นเร็วขึ้น) · 🏦 ธนาคาร (ดอกเบี้ย 3%/วัน, กู้ได้ ฿30,000)

📜 **เควสต์ประจำวัน** วันละ 3 ข้อ (ตามอาชีพ / กับผู้เล่นอื่น / ทั่วไป) รีเซ็ตเที่ยงคืนเวลาไทย ทำครบได้โบนัส ทำครบติดกันหลายวันโบนัสเพิ่ม เปลี่ยนเควสต์ได้วันละ 1 ข้อ

ทุกคนต้องกินอาหาร ดูแลพลังงาน/สุขภาพ มีเหตุการณ์สุ่มทั้งเมือง (ภัยแล้ง เทศกาล ไข้หวัด ฯลฯ) และราคาตลาดแชร์กันทั้งเมือง

## วิธีเล่น
- **เดิน**: มือถือแตะค้างแล้วลาก (จอยลอย) · คอม WASD / ลูกศร
- **ใช้สถานที่**: เดินเข้าไอคอนลอย แล้วกดปุ่มกลมสีเหลือง (คอม: E)
- **เจอผู้เล่นอื่น**: แตะที่ตัวเขา → ขอแลกเปลี่ยน / โดเนท / เสนอรักษา
- **เสียง**: มีเสียงเอฟเฟกต์และเพลงประกอบ (สร้างด้วย Web Audio ไม่ต้องโหลดไฟล์) ปิด/เปิดที่ปุ่ม 🔊 หรือเมนู ❔
- เล่นต่อได้ด้วยชื่อ + PIN 4 หลัก (เซฟลง Postgres ถ้ามี `DATABASE_URL` ไม่งั้นเซฟที่ `data/players.json`)

## รันบนเครื่อง
```
npm install
npm start          # http://localhost:3000
```
เพื่อนใน Wi-Fi เดียวกันเข้าที่ `http://<IP เครื่องคุณ>:3000`

## Deploy ให้เพื่อนเล่นออนไลน์ (ฟรี)
เกมนี้ใช้ WebSocket ต้องรันบนเซิร์ฟเวอร์ Node.js (ใช้ Streamlit Cloud ไม่ได้) ตัวอย่างบน [Render](https://render.com):
1. New → **Web Service** → เลือก repo นี้และ branch ที่ต้องการ
2. Render อ่าน `render.yaml` ให้เอง (Build: `npm install`, Start: `npm start`)
3. ได้ลิงก์ `https://xxx.onrender.com` ส่งให้เพื่อนได้เลย

### เก็บข้อมูลผู้เล่นถาวร (แนะนำ)
ถ้าไม่ตั้งค่าอะไร ข้อมูลจะเก็บในไฟล์ ซึ่งหายทุกครั้งที่ Render deploy/รีสตาร์ท ให้ใช้ Postgres ฟรีแทน:
1. สร้างฐานข้อมูลฟรีที่ [Neon](https://neon.tech) (หรือ Supabase) แล้วคัดลอก **connection string** (ขึ้นต้นด้วย `postgresql://`)
2. ใน Render → service → **Environment** → Add `DATABASE_URL` = connection string นั้น → Save
3. เซิร์ฟเวอร์สร้างตารางให้เอง เซฟทุก 15 วินาทีและตอนปิด เห็นข้อความ `storage: Postgres` ใน Logs

### กันเซิร์ฟเวอร์หลับ
บน Render เซิร์ฟเวอร์จะ ping ตัวเองทุก 9 นาที (ใช้ `RENDER_EXTERNAL_URL` ที่ Render ใส่ให้เอง หรือกำหนด `KEEPALIVE_URL` เอง) จึงไม่หลับตอนไม่มีคนเล่น

## โครงสร้าง
- `server/data.js` แผนที่ สถานที่ ไอเทม อาชีพ
- `server/quests.js` เควสต์ประจำวัน
- `server/store.js` ที่เก็บข้อมูลผู้เล่น (Postgres / ไฟล์)
- `server/index.js` เซิร์ฟเวอร์ (HTTP + WebSocket, ตรรกะเกมทั้งหมดอยู่ฝั่งเซิร์ฟเวอร์ ตรวจความเร็วเดิน/ระยะ/ของที่มีจริง)
- `public/game.js` ไคลเอนต์ (canvas) · `public/fx.js` เสียงและเอฟเฟกต์
