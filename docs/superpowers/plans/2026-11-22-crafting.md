# Crafting v1 Implementation Plan
**Goal:** craft-only furniture at a town workshop. **Spec:** docs/superpowers/specs/2026-11-22-crafting-design.md
**Stack:** Node, no new deps. Tests: `node server/craft.test.js` (node:assert).

## Review Focus
1. Crafting with too few inputs must change nothing (no item loss). 2. Double-tap craft of a non-multi piece already owned → refused, inputs kept.
3. Gem shard buy with too few gems → refused, gems unchanged; qty clamped 1..10. 4. Crafted pieces never purchasable in shops.
5. gshard cannot be sold for money.

### Task 1: data + pure logic (server/craft.js, server/data.js)
- Test: `craft.test.js` — drop() rolls with injected rnd; craft() ok/refusals (missing input, owned, unknown id); buyShard() ok/refused/clamped; every CRAFTS input is an ITEM and output is FURNITURE with craft:1.
- `drop(a, key, D, rnd=Math.random) -> string[]`, `craft(a, rid, D) -> {ok, msg, f?}`, `buyShard(a, n, D) -> {ok, msg, n?}`.
### Task 2: server wiring (server/index.js)
- stat() calls drop + toast; `craft.make` / `craft.shard` actions at station type `craft`; shop buy refuses `f.craft`; sell refuses `it.nosell`; mail gift `items`; contest top 3 shards.
### Task 3: client (public/game.js) + NEWS
- panel `craft`; shop lists filter `!f.craft`; legend glow; NEWS entry.
